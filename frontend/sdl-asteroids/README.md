# Myll Asteroids

A wireframe Asteroids clone in [Myll](https://github.com/JanSordid/Myll), rendered with SDL3.

## Build and run

```bash
make
./gen/asteroids
```

## Controls

- Left / Right — rotate
- Up — thrust
- Space — shoot
- Window close — quit

## Features

- 640×360 internal resolution for clean integer upscaling.
- Random wireframe asteroids with rotation and wrap-around movement.
- Asteroid splitting on hit, respawn on death, and per-level escalation.
