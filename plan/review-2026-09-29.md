# Backend review — 2026-09-29

Status: **open**. This is the index for the backend code review performed on 2026-09-29.

The review covered all of `backend/` (Core, Visitor, Resolver, Transform, Generator, Grammar) plus the
frontend driver, build files, `std/`/`lib/` bindings, and the test harness. Four parallel review passes
ran over the code. Every high-severity finding was re-verified in this session, either by compiling a
repro or by reading the cited code. Repro sources live in `tmp/review/` (scratch, not committed).

## Method

- Read-only review, then targeted repros in `tmp/review/` compiled via the frontend CLI and, where
  relevant, checked with `clang++ -std=c++23 -Wall -Wextra`.
- Findings are split into `bug-*.md` (something is observably wrong) and `enhancement-*.md`
  (structure, duplication, or performance work).
- One reported bug was **refuted** during verification: `VisitDefConvert` text-parsing of the
  `convert`/`conv` alias does not invert semantics today, because the `CONVERT` token belongs to the
  parent `declConvert` rule and never appears in the `defConvert` context that is text-parsed. Both
  spellings work (repro: `tmp/review/conv_alias.myll`, `conv_alias2.myll`). The text-parsing is still
  fragile and the `StartsWith("convert")` branch is dead code. See `bug-convert-ctor-syntax.md`.
